## What the user wants
A genre-independent symbolic-music engine accepting compatible Guitar Pro `.gp` scores. Learn musical relationships and generate novel `.gp` compositions. Independent controls for chord progression, chord-relative melodic function+octave, rhythm, structure, performance, and arrangement. 0% must **exactly lock** a feature; greater values should ultimately represent **measured musical distance**, not a probability of random edits. Do not hardcode metal riffs, one key, 4/4, fixed four-bar phrases, or root/chug assumptions.

## Current implemented layers
- Lossless-ish exact rational beat-time/voice/track/note extraction (`extract.py`, `music_events.py`); GP archive writer and safe per-occurrence editing (`gp_occurrence_writer.py`, `gp_similarity_export.py`). Verify round-trip for each target GP variant; no claim of fully lossless GP format coverage.
- Broad chord vocabulary, evidence-based harmonic hypotheses, partial-chord conservative interpolation, and chord-relative functional mapping (`harmonic_inference.py`, `harmonic_relative.py`, `harmonic_continuity.py`, `contextual_harmony.py`). Inferences can remain unresolved. Chord role mapping preserves degree and octave; nonchord notes often fall back to offset from chord root.
- `similarity_controls.py` with independent chord/melody/rhythm knobs. 0% identity path is tested; nonzero % presently means edit attempts or stochastic variation, NOT perceptual distance calibration. GP export is opt-in for newer learning modes.
- Source-derived rhythmic/melodic substitution (`learned_patterns_v16.py`), chord-independent melodic interval learning (`relational_learning_v17.py`), candidate variable-length phrase segmentation (`phrase_discovery_v19.py`), and opt-in coupled motif/harmonic/phrase evidence (`joint_interpretation_v20.py`). These are heuristic/statistical prototypes, not a trained end-to-end joint probabilistic model or validated musical phrase recognizer.
- V21 five-score evaluation (`evaluate_v21.py`), V22 unlabeled review scorer (`reference_validation_v22.py`), V23 offline listening-review generator/player (`v23-review/`, root `composition-review.html`), V24 extraction of source-authored chords and section annotations (`source_annotations_v24.py`).

## Verified observations / limits
- V21 reviewed bounded excerpts of five scores (Chet Baker; Sweet Child O' Mine; Cloud Cascade; Nocturne Lost Faith; Immolation of Night): 767 attacks, 114 unambiguous chord-template matches (14.9% **match coverage**, not accuracy). 60 review cases selected. No human-reviewed labels: do not report chord/phrase accuracy.
- V22 evaluator: 90 local tests passed at that version; accuracy intentionally unavailable without human labels.
- V23: standalone synthesized Web Audio playback with 60 embedded cases, local CSV export compatible with V22; 7 targeted tests; interactive browser QA not established. The GitHub Pages site has root `composition-review.html` and a navigation link in `index.html` as of this handoff.
- V24: 69 source-authored chord diagram occurrences in Chet Baker, 54 section markers across five files, 3 of 60 selected review attacks co-located with source chord symbols; no human labels. Source annotations are not ground truth or necessarily sustained across beats. V24 targeted tests 7/7 pass locally. `V24_review_with_source_annotations.csv` adds context without changing human-label fields.
- V18 fixed repeated-GP-definition issue (previously only 4–8 actual note edits in V17; V18 exported 102 melody-only changes in its Chet example). V19 found 50 candidate gestures/387 windows; V20 found 344 refinement windows and 97 exported note edits on Chet. These edit counts are NOT proof of musical quality.

## Reproduce
Use Python with existing dependencies from repo/environment (GP parser and unit tests). From the checkpoint folder, e.g. `python -m unittest discover -p 'test_*.py'`. Run focused `python -m unittest test_source_annotations_v24.py` for V24 (7 tests as last checked). Source GP files must be obtained separately; they're user-provided score files, NOT assumed present in GitHub due to copyright. V24 `python source_annotations_v24.py` requires its expected source paths, V21 review CSV, and source scores; check CLI/code before running. Do not fabricate test results if the environment differs.

## Important safety of evaluation
- Chord template fit ≠ correctly identified harmony.
- Source chord diagram name ≠ adjudicated reference.
- Section marker ≠ human phrase segmentation.
- Unit tests ≠ end-to-end listening quality or browser QA.
- Positive change counts ≠ similarity metric calibration.
