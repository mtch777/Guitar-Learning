# Common harmonic evidence: bounded START contract

2026-10-28. Design and acceptance contract. No new detector, inferred source
label, creative policy or independent pitch stream is authorized by this file.

## Priority and existing relationships

Park `TEMPORAL_TEXTURE_CONTINUITY_START.md`: minimum-motion correspondence is
not the next implementation. Its cost optimum would not establish melody.

Unlabeled source chords already have conditional interpretations in
`musical_tier2.interpreted/context`. `chord_degree_relations.note_role` and
`pitch_from_degree` already solve the exact shared degree equation.
`contextual_passage_roles` already exposes conditional interval/completion roles.
The missing integration is a common evidence contract usable by source pattern
catalogs even when no literal source chord annotation exists. Do not reimplement
those functions or call every unlabeled group musically unresolved by definition.

## Initial scope and ownership

- Complete coattack group, exact source occurrence partition, part/bar/rational
  onset and every member's original identity. No inferred annotation duration.
- Existing pinned 50-form definitions and every root: retain all exact observed
  PC-set fits. This stage does not add incomplete templates/unplayed tones,
  interval segmentation, heuristic rankings or scored six-family substitutes.
- Require the same explicit known-pitch/timing/domain eligibility as the
  existing relation. Partial-known groups are not certified complete-PC fits.
  Percussion, unknown pitches/domains and insufficient pitch evidence retain
  explicit statuses and the full source denominator.
- Literal source label evidence remains distinct, exact and provenance-linked.
  No label is synthesized or written back to T1. A source label may disagree
  with observed fits; neither evidence class silently overwrites the other.
- A singleton fit means only one fit within this finite theory vocabulary. It
  does not establish actual root, intended chord, key/mode, function or emotion.
- Existing declared-degree ownership remains authoritative where already
  admitted. Other groups retain their existing coattack/family pitch owner.
  Conditional evidence refers to those owners; no duplicate root/pitch backup.

Each hypothesis identifies its evidence class, source group/members, root/kind,
canonical formula, all supported degree spellings/aliases, exact member-degree
relationships, observed support and uncertainty. Distinguish a theoretical
interpretation ID from a literal source declaration fact ID. No preferred root.

## Shared relation and actual use

Reuse `pitch = root_pc + theoretical_degree_semitones + 12*relative_octaves` in
both directions, including compound degrees and negative registers. Every
stored coordinate and hypothesis is recomputed and checked against the SAME
authoritative reconstructed occurrences in the stripped inverse.

The practical deliverable is hypothesis-indexed **source degree-pattern** input
to existing catalog analysis, not an isolated second report of note roles.
Retain candidate-to-source-pattern and candidate-to-assumption provenance.
Concrete target-pitch layouts must be deduplicated across equivalent witnesses;
keep assumption-dependent outputs distinct from universally consistent ones.
Do not collapse ambiguous degree aliases to manufacture a unique pattern.

No selection/admission policy changes in this experiment. Existing literal
outer-note locks, source execution/ties/techniques, physical guards and exact
zero remain unchanged. Conditional evidence alone cannot authorize an edit.

## Frozen population and accounting

Use all six existing frame development cases plus all three fresh frame cases,
with source/capture/code hashes frozen before results. Fresh frame cases become
development for this new interface; do not call them fresh for its eventual gate.
Do not add songs until a desired chord or alternative appears.

Count unique original captures and group/occurrence IDs once, not once per
hypothesis, label, donor alias or root. Report at least:

- All groups/members; every ineligible/unknown/refused status.
- Labeled/unlabeled groups separately; complete exact-fit groups and no-fit
  groups; fit multiplicity; ambiguous degree-assignment counts.
- Unique source degree patterns and concrete target layouts, separately from
  hypothesis/witness/donor-link counts.
- Existing declared evidence agreements/disagreements and coverage differences.
- Universally consistent versus assumption-dependent candidate relations,
  without treating either count as artist-fit or audio quality.

## Testable acceptance checklist

- [x] START scope approved before implementation; temporal-motion experiment parked.
- [x] Producer reuses current theory/degree/pitch functions and owner references.
- [x] Independent raw/native oracle checks every exact-fit root/formula and
  every member coordinate, complete source membership and typed provenance.
- [x] Contrasts include C6/Am7 ambiguity, symmetric diminished roots, power/dyad
  insufficiency or exact alternatives, compound degrees, enharmonic degree
  ambiguity, percussion, partial unknown pitch and invalid timing.
- [x] Label masking leaves observation-derived fit hypotheses unchanged;
  changing a label changes only declared evidence. Source string/serialization
  changes cannot invent a harmonic preference. Global transposition maps all
  roots and degree equations equivariantly without dropping alternatives.
- [x] Missing/extra hypotheses, omitted members, duplicate aliases, forged
  source-label provenance, Boolean IDs/degrees/registers and stale coordinates
  are rejected by the SAME reconstruction-time relation.
- [x] Complete frozen nine-case accounting and MID independent review.
- [x] Actual source-denied full-source and relationship-pair workers prove
  exact zero and recomputation with lower files/cache/expected output absent.
- [x] Preregister bounded fresh-source gate after stable code; preserve failures
  and zero-coverage outcomes. No no-fit or singleton outcome becomes truth.
- [x] END states source portability, exact inverse and bounded musical-evidence
  validity separately. No creative/audible/artist or full Tier2 completion claim.

The finite done condition is complete common evidence and source-pattern
integration with exact uncertainty/provenance and the above checks. Expanding
theory vocabulary, choosing tonic, inferring melodic lines and enabling a
creative control each need a separate contract; they are not automatic followups.
