# T5: live return of an earlier arrangement

## Musical result and limit

An earlier chorus can use a lower, spaced guitar pattern. At a later chorus,
choose to recall that LIVE material choice or retain the original independent
pattern. Changing the earlier choice after saving propagates only when linked.
This controls the paired guitars in the first four bars of two existing choruses;
it does not claim automatic form discovery, arbitrary melody development or a
complete T5. The whole song, intervening music and ending are played intact.

Input is T4. T5 removes the return's material reference and owns one conditional
dependency. T4 choices and T3 timed material placement solve it downward through
the existing inverse. One canonical definition represents the repeated idea;
newly redundant return definitions are removed after exact lower-model equality.
Inherited definitions, occurrence/use identities, original observations and all
other obligations remain unchanged. Return-specific expression and drums remain
independent. An independent material ID is an explicit realization choice.

0 locks the current intention. 50 is seeded release probability. 100 removes
preference for the current intention, not a promise of audible difference.
Feasibility is checked before nonzero sampling; an impossible recall cannot be
reported as accepted just because a draw retains the independent state.
