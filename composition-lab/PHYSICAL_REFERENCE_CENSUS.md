# Physical reference census — investigate before integrating

Question: do existing captured scores contain complete, independently observed
fret shapes for inner-voicing choices that reach the physical-evidence check?
Passing that check would still require every later context/technique check.

This is a physical-evidence experiment. Musical component donors remain inside
the current song. Absence of a shape is not evidence of unplayability. A notation
witness is not a human playability or artist-fidelity judgment.

- [x] Planner MID/END: challenge interpretation and determine the next action.

## Architecture boundary

Do not change the inverse for this census. A later accepted model must enter
explicitly before forward analysis, with one owner and typed references. It must
never be discovered through source/cache/network access during reversal or
embedded as learned constants in engine code. Exact zero must not require it.

Normalized geometry is an analysis result, not a raw Tier1 source fact. If a
conditioning capsule is supplied separately, exact reconstruction covers the
complete owned target and that capsule—not the original reference scores.
Reconstructing a full multi-song input would require preserving each song's
owners. This distinction must be resolved in a concrete interface before use.

No engine integration or new creative pass is claimed by this investigation.
